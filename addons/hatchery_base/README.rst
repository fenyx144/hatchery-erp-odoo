Incubación: datos maestros
===========================

Catálogos de planta, granja, máquina, sensor y programa de incubación.

Los nombres de granjas, máquinas y consignas que trae el demo son ficticios.
No se escribe en las máquinas ni en el SCADA.
Las preguntas abiertas están en ``docs/PREGUNTAS.md``.
